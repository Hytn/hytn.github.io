🏆 **My role: Agent Capability Lead**

[![Stars](https://img.shields.io/github/stars/OpenBMB/MiniCPM?style=social)](https://github.com/OpenBMB/MiniCPM) · `6.9M+ Downloads`

MiniCPM5 is an open-source LLM series built for on-device, local, and resource-constrained deployment, with a native 128K context and out-of-the-box support in mainstream inference engines. I led the end-to-end construction of its agentic capabilities: tool-calling and multi-turn interaction data, agentic reinforcement learning, and the evaluation suite.

**Key results:**
- 🥇 The 2B model leads its size class on agentic benchmarks such as BFCL v4, τ²-Bench, SWE-bench Verified, and GAIA, and its overall average surpasses the larger Qwen3.5-4B
- 📦 MiniCPM5-1B and MiniCPM5-2B (including GGUF / MLX variants) have each reached about 3.45M cumulative downloads on Hugging Face — over 6.9M in total
- 🔌 Ships with an OpenAI-compatible tool-calling parser and Agent Skills for coding agents
